🤖 Autonomous Agent Guide

How to assign work to different agents for parallel development

✅ Safe for Parallel Agents

Example: Add User Profiles + Sound Effects + Analytics

Agent A: User Profile System
  • Domain 1: Add UserProfile model
  • Domain 4: Add profile API endpoints
  • Domain 5: Add ProfileScreen.tsx
Agent B: Sound Effects
  • Domain 5: Add sound effects to Player
  • Domain 6: Add sound effects to DJ Panel
  • Domain 7: Add sound effects to Display
Agent C: Analytics Dashboard
  • Domain 2: Add statsService.ts
  • Domain 4: Add analytics endpoints
  • Domain 6: Add AnalyticsDashboard.tsx

Why it works: Different domains, no file conflicts, independent features

⚠️ Requires Sequential Execution

Example: Team Mode Feature

Step 1 - Agent A: Database Schema
  • Create Team model
  • Create TeamMember model
Step 2 - Agent B: Backend Logic
  • Add teamService.ts (depends on models)
  • Add team API endpoints
Step 3 - Agent C: Frontend
  • Add team creation UI (depends on API)
  • Add team gameplay logic

Why sequential: Each step depends on the previous one

💡 How to Request Agent Work

For parallel work, say:

"I need to add these features in parallel:
1. Player profile system with avatars
2. Sound effects for all interfaces
3. Export game results to CSV

Please use separate agents for each."

For sequential work, say:

"Add team mode feature:
1. First, plan the database schema
2. Then implement the backend logic
3. Finally, build the UI"
